# 🌐 Subhajit Das — Portfolio Website

This is a **personal portfolio website** built by Subhajit Das, a B.Tech CSE student at MSIT.  
The site showcases his **skills**, **projects**, and **contact information** in a clean, modern, and fully responsive design.

[🌐 Live Demo](https://subhajitindia99das.github.io/Portfolio/) • [📁 GitHub Repo](https://github.com/Subhajitindia99das/Portfolio)

![GitHub language count](https://img.shields.io/github/languages/count/Subhajitindia99das/Portfolio)

---

## 📌 Tech Stack Used

- 🌐 HTML5  
- 🎨 CSS3  
- ⚙️ JavaScript (Vanilla)  
- 💡 ScrollReveal.js (for animations)

---

## 🚀 Key Features

- 🌙 Light/Dark Mode Toggle  
- 📱 Fully Responsive Layout  
- 🧭 Smooth Scroll Navigation  
- ✨ Scroll Animations using ScrollReveal.js  
- 🗂️ Project Section with GitHub links  
- 📩 Contact Form with floating labels  
- 🍔 Mobile Hamburger Menu  
- 📎 Clean, modern UI with custom styling

---

## 📄 Sections Included

- Home  
- About Me  
- Skills  
- Projects  
- Contact  
- Footer with social media links
